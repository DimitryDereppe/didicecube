# Relations entre les entités du projet

Quelles entités possèdent des liens logiques entre elles ?

- UTILISATEUR — PROGRESSION : un utilisateur **possède** zéro ou plusieurs
  progressions sauvegardées
- UTILISATEUR — SKIN : un utilisateur **télécharge** zéro ou plusieurs skins
- SKIN — IMAGE_SKIN : un skin **se compose de** zéro ou plusieurs images
  (une par couleur remplacée)
